# Privacy Policy

The published privacy policy for the Secure Gateway Studio Chrome extension is
at:

**<https://dymzd.github.io/Google/privacy.html>**

That page is the copy referenced from the Chrome Web Store listing and the
Google OAuth consent screen, and it is the one to read.

Its source is [`docs/privacy.md`](../../docs/privacy.md) in this repository.
It lives there rather than here so that there is exactly one copy: a second
file would drift from the published page, and a privacy policy that disagrees
with itself is worse than one that is inconvenient to find.
